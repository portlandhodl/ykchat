How do I find my GPG fingerprint?
  1. Open a terminal and run:
    gpg --list-secret-keys --fingerprint
  2. Copy the 40-character line under sec (your primary key), not the ssb subkeys.
  1. GPG Suite: open GPG Keychain, double-click your key and copy the Fingerprint.
  2. Homebrew (brew install gnupg pinentry-mac): in Terminal run
    gpg --list-secret-keys --fingerprint
    and copy the 40-character line under sec.
  1. Kleopatra (part of Gpg4win): select your key under Certificates and copy the fingerprint from the Details pane.
  2. PowerShell:
    gpg --list-secret-keys --fingerprint
    then copy the 40-character line under sec. Use PowerShell, not cmd.exe, for the signing step too.

Example output

sec> ed25519 2025-03-14 [SC] 4853 B8A6 AC40 E551 3372 3A1A 6554 2D79 E5A6 7972 Card serial no. = 0006 12345678 uid [ultimate] Alice Example <alice@example.com> ssb> cv25519 2025-03-14 [E]

Keys on a YubiKey show as sec> with a card serial. If nothing is listed, import your public key (gpg --import mykey.asc) and run gpg --card-status once so GnuPG links the card.
